# Mohammed Sakarwala - Portfolio

Static, responsive portfolio website for Mohammed Sakarwala. The site is published from this repository root with GitHub Pages.

- Home: introduction, selected work, services, experience, and contact
- About: personal background, working philosophy, journey, and interests
- Works: project gallery and case studies for Chaska, YŌJŌ, and OM Notes

The homepage uses a forest-green and sage palette, PP Editorial Old for display headings, and PP Neue Montreal for body text.
